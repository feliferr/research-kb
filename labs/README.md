# Labs

Mini-projetos de prototipação, um por pasta: `labs/<slug>/README.md` (a partir de [templates/lab.md](../templates/lab.md)) com o código e os resultados ao lado.

Regras:

- Cada lab liga a uma fonte (`source:` no frontmatter) e tem critério de pronto definido antes de começar.
- Tarefas de 1 a 2 horas, para caberem em um bloco de estudo.
- Datasets, checkpoints e saídas pesadas ficam fora do git (ver `.gitignore`); o README diz como obtê-los.
- Um lab só vira `done` com a seção "O que aprendi" preenchida.
